# EchoVocab 靈語單字 — 智慧 AI 個性化英文學習系統 🌟

專為高效、無痛、個性化記憶英文單字設計的現代化 Web 應用程式。整合 **Google Gemini AI**、**艾賓浩斯間隔重複遺忘曲線 (SM-2 SRS)**、**自然真人語音 (TTS)** 與 **CSV 完整資料匯入/匯出**。

---

## 🚀 核心亮點功能

### 1. 🤖 Gemini AI 智慧擴充與自訂新增
- **AI 智能秒級解析**：輸入一個或多個生詞、片語甚至整段句子，Gemini 自動生成：
  - 國際音標 (IPA)
  - 正確常用詞性
  - 準確繁體中文釋義
  - 2句符合生活或職場語境的雙語例句
  - **超有趣諧音梗 / 字根字首記憶口訣**（過目不忘秘訣！）
  - 智慧推薦分類標籤
- **情境主題單字擴展器 (Beyond Expectation)**：
  - 輸入任意生活情境（如「星巴克點餐」、「機場過海關」、「外商薪資談判」），AI 一秒為你生成量身打造的高頻核心生詞包！
- **手動錄入與 AI 輔助**：可自行填寫所有自訂欄位，並支援「AI 一鍵補齊音標與例句」按鈕。

### 2. 🎴 3D 翻卡測試 (SM-2 艾賓浩斯記憶法)
- **立體 3D 卡片翻轉**：正面英文發音與音標，反面詳細中文、例句與口訣。
- **SM-2 間隔重複算法 (SRS)**：提供「忘記了 (Again)」、「有難度 (Hard)」、「記住了 (Good)」、「太簡單 (Easy)」四級評定，系統自動計算 1天、3天、7天、14天、30天等下次複習日期。
- **極速快捷鍵操作**：
  - `Space 空白鍵`：翻轉卡片
  - `數字鍵 1 ~ 4`：快速打分並進入下一張
  - `R 鍵`：即時重聽真人朗讀
- **複習結算與彩帶慶祝**：完成今日待複習目標時，自動觸發 Confetti 彩帶特效與連續打卡記錄。

### 3. ✍️ 拼字大挑戰 (Spelling Quiz)
- **聽音辨字 + 中文提示**：強化主動提取記憶 (Active Recall)。
- **連擊 Combo 與積分系統**：連續答對激發學習動力。
- **貼心輔助**：遮罩長度提示、首字母揭露按鈕。
- **純代碼 Web Audio 音效**：即時合成正確音效、錯誤震動反饋。
- **鍵盤 Enter 鍵** 立即送出，體驗行雲流水。

### 4. 🌈 超乎預期功能 (Beyond Expectations)
- **AI 外教實戰造句評分 (Sentence Lab)**：
  - 挑選庫存單字自己造句，Gemini 即時扮演外教打分 (0-100分)。
  - 詳細診斷文法時態、母語者道地程度，並提供**母語級潤色重寫版本**與一鍵朗讀！
- **AI 生詞串聯情境故事 (Story Generator)**：
  - AI 抽取今日待複習的生詞，串聯寫成一篇趣味英語短文，單字加粗標記，在完整語境中牢固掌握。
- **自然真人朗讀 (Web Speech API)**：
  - 支援系統美式/英式發音人自選、語速調速 (0.7x ~ 1.3x)、翻卡自動發音開關。
- **連續學習打卡 (Streak Tracker)**：
  - 首頁火焰打卡計數器，維持每日學習習慣。

### 5. 🔄 CSV 完整匯入與匯出 (Data Center)
- **繁體中文防亂碼 (UTF-8 BOM)**：匯出的 CSV 自帶 UTF-8 簽名，在 Windows Excel / Mac Numbers / Google 試算表直接點開**絕不亂碼**！
- **彈性 CSV 匯入引擎**：支援直接拖曳 CSV 檔案、即時表格預覽、支援「合併更新」或「完全覆蓋」。
- **全量 JSON 備份/還原**：連同 SRS 記憶曲線進度、連續天數一併保存，隨心跨裝置轉移。
- **附贈範例單字檔**：內建 `sample_vocabulary.csv`，方便直接體驗匯入！

## 💻 如何開始使用？

### 方法一：直接雙擊打開（免安裝任何環境）
1. 在資料夾中找到 **`index.html`**。
2. 用任何現代瀏覽器（Google Chrome, Edge, Safari, Firefox）雙擊打開即可！
3. 所有學習資料儲存在瀏覽器本地 (LocalStorage)，離線也能背單字！

### 方法二：透過本地輕量伺服器開啟（可選）
若您習慣透過本地伺服器運行，可在終端機執行：
```bash
npx serve .
# 或
python -m http.server 8000
```
並於瀏覽器前往 `http://localhost:8000`。

## 🔑 如何設定 Gemini API Key？

1. 點擊網頁右上角的 **⚙️ 設定圖示**。
2. 在「Google Gemini API Key」欄位貼上您的 API Key（可前往 [Google AI Studio](https://aistudio.google.com/) 免費獲取）。
3. 點擊「測試連線」，成功後點擊「儲存設定」。
4. *註：若尚未輸入 API Key，系統也內建了「示範模式」，您依然可以體驗情境產生與 AI 造句功能！*
