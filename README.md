# EchoVocab 靈語單字 — 智慧 AI 個性化英文學習系統

專為高效、無痛、個性化記憶英文單字設計的現代化 Web 應用程式。整合 **Google Gemini AI**、**艾賓浩斯間隔重複遺忘曲線**、**電腦語音** 與 **CSV 完整資料匯入/匯出**。


## 核心亮點功能

### 1. Gemini AI 智慧擴充與自訂新增
- **AI 智能秒級解析**：輸入一個或多個生詞、片語甚至整段句子，Gemini 自動生成：
  - 國際音標 (IPA)
  - 正確常用詞性
  - 準確繁體中文釋義
  - 兩句符合生活或職場語境的雙語例句
  - **超好笑/好記的「諧音聯想梗」或「字根字首記憶口訣」**
  - 智慧推薦分類標籤
- **截圖/照片多模態生詞提取**：看美劇、英文書直接截圖貼上 (`Ctrl+V`)，Gemini 視覺模型自動萃取重點難字！
- **情境主題單字擴展器**：輸入任意生活情境（如「星巴克點餐」、「機場過海關」），AI 一秒生成量身打造的高頻核心生詞包！
- **手動錄入與 AI 輔助**：可自行填寫所有自訂欄位，並支援「AI 一鍵補齊音標與例句」按鈕。

### 2. 3D 翻卡測試
- **立體 3D 卡片翻轉**：正面英文發音與音標，反面詳細中文、例句與口訣。
- **SM-2 間隔重複算法**：提供「忘記了」、「有難度」、「記住了」、「太簡單」四級評定，系統自動計算 1天、3天、7天、14天、30天等下次複習排程。
- **極速快捷鍵操作**：
  - `Space 空白鍵`：翻轉卡片
  - `數字鍵 1 ~ 4`：快速打分並進入下一張
  - `R 鍵`：即時重聽真人朗讀

### 3. 拼字大挑戰
- **聽音辨字 + 中文提示**：強化主動提取記憶 (Active Recall)。
- **連擊 Combo 與積分系統**：連續答對激發學習動力。
- **貼心輔助**：遮罩長度提示、首字母揭露按鈕。
- **即時音效反饋**：Web Audio API 純代碼合成清脆答對音效與錯誤震動。
- **注意事項**：請勿使用「**華碩智慧輸入法**」這類的會自動選字核心，或**華碩智慧輸入法**請使用純英文模式。

### 4. 聽力盲測模式
- 專門拯救「看得懂但聽不懂」的痛點！
- 隱藏英文拼寫，只播放真人語音發音，四選一快速測驗耳朵敏銳度。

### 5. CSV 完整匯入、匯出與 A4 小抄列印
- **防亂碼 UTF-8 BOM**：匯出 CSV 在 Excel / Google 試算表直接開啟絕無亂碼。
- **A4 隨身口袋單字小抄**：一鍵生成中間有折疊線的雙欄單字表，折疊後通勤隨身自測！
- **全量 JSON 備份/還原**：隨心跨裝置轉移學習紀錄。
